# STM32-Motor-Control-System
Precise DC motor speed and direction control using an STM32. Implements hardware PWM for speed regulation and reads an ADC-connected potentiometer for real-time user input.

A real-time DC motor control system built with an STM32 microcontroller and an L298N H-bridge driver. This project provides precise, bi-directional control over a motor's speed using **PWM** signals generated by hardware timers and an **ADC** for user input.

<br>


---

## ## Features

* **Precise Speed Control:** Uses STM32's hardware **Timer (TIM)** peripheral to generate a stable, high-frequency **PWM** signal, allowing for fine-grained speed control with 8-bit resolution (256 distinct steps).
* **Bi-Directional Control:** Implements an **L298N H-bridge driver** to control the motor's direction (clockwise and counter-clockwise) by managing logic levels on GPIO pins.
* **Real-Time User Input:** A potentiometer is read by the STM32's **ADC (Analog-to-Digital Converter)**, instantly translating the analog user input into a digital PWM duty cycle.
* **Low Latency:** Achieves a measured system latency of **<100ms** from potentiometer adjustment to the corresponding change in motor speed.

## ## How It Works

The system is built on two core STM32 peripherals: the ADC for input and a Timer for output.

1.  **Speed Input (ADC):** A 10k potentiometer is set up as a voltage divider. The center tap is connected to an ADC pin on the STM32. The microcontroller continuously polls this pin, converting the analog voltage (e.g., 0V to 3.3V) into a digital value (e.g., 0 to 4095 for a 12-bit ADC).

2.  **Speed Control (PWM):** A hardware Timer (e.g., `TIM2`) is configured in **PWM Generation** mode. The digital value from the ADC is mapped to the timer's duty cycle range (e.g., 0 to 100%). This PWM signal is sent to the L298N's `ENA` (Enable) pin, which effectively controls the average voltage—and thus the speed—delivered to the motor.

3.  **Direction Control (GPIO):** The L298N driver has two logic inputs, `IN1` and `IN2`. The motor's direction is determined by the state of these pins:
    * `IN1` = HIGH, `IN2` = LOW  -> Clockwise
    * `IN1` = LOW, `IN2` = HIGH  -> Counter-Clockwise
    * `IN1` = LOW, `IN2` = LOW   -> Brake
    These pins are connected to standard GPIO output pins on the STM32, which are set by the program (e.g., could be hard-coded or controlled by buttons).

## ## Setup & Installation

### ### 1. Hardware Wiring

1.  **Power:** Connect all `GND` pins together. Provide the L298N with its 5V logic (`VCC`) and 9V-12V motor (`VMOT`) power.
2.  **Input (ADC):** Connect the potentiometer's outer pins to 3.3V and GND. Connect the center pin to the STM32's ADC pin (e.g., `PA0`).
3.  **Output (PWM):** Connect the STM32's Timer PWM pin (e.g., `PA5` for `TIM2_CH1`) to the L298N's `ENA` pin.
4.  **Output (Direction):** Connect two STM32 GPIO pins (e.g., `PC0`, `PC1`) to the L298N's `IN1` and `IN2` pins.
5.  **Motor:** Connect the DC motor to the L298N's `OUT1` and `OUT2` screw terminals.

*(You would typically add your own schematic/wiring diagram image here)*

### ### 2. STM32CubeIDE Configuration

1.  Start a new project in STM32CubeIDE for your board.
2.  In the `.ioc` (pinout configuration) tool:
    * Go to **Timers** -> **TIM2** -> Set **Channel 1** to `PWM Generation CH1`. Set the `Prescaler` and `Counter Period` (ARR) to achieve your desired frequency (e.g., 10kHz).
    * Go to **Analog** -> **ADC1** -> Enable `IN0` (or the pin connected to the pot).
    * Configure your two direction pins (e.g., `PC0`, `PC1`) as `GPIO_Output`.
3.  Generate the initialization code.

### ### 3. Code (`main.c`)

1.  **Start the peripherals** in `main()` before the `while(1)` loop:

    ```c
    // Start the Timer in PWM Mode
    HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);

    // Set initial motor direction (e.g., Clockwise)
    HAL_GPIO_WritePin(GPIOC, GPIO_PIN_0, GPIO_PIN_SET);   // IN1
    HAL_GPIO_WritePin(GPIOC, GPIO_PIN_1, GPIO_PIN_RESET); // IN2
    ```

2.  **Add the main logic** inside the `while(1)` loop:

    ```c
    uint32_t adc_val;
    uint16_t pwm_val;

    // Start ADC conversion
    HAL_ADC_Start(&hadc1);

    // Poll for conversion to be complete
    if (HAL_ADC_PollForConversion(&hadc1, 100) == HAL_OK)
    {
        // Read the ADC value (0-4095 for 12-bit)
        adc_val = HAL_ADC_GetValue(&hadc1);

        // Map the 12-bit ADC value to the 8-bit PWM duty cycle (0-255)
        // Note: Assumes Timer ARR is set to 255 for 8-bit resolution
        pwm_val = (uint16_t)(adc_val / 16.0); 
    }

    // Set the PWM duty cycle
    __HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, pwm_val);

    // Stop the ADC to prepare for the next loop
    HAL_ADC_Stop(&hadc1);

    // Delay for stability
    HAL_Delay(50);
    ```

## ## Usage

1.  Power on the entire circuit.
2.  The motor will be stationary (or at its lowest speed) if the potentiometer is at 0%.
3.  Slowly turn the potentiometer. You will see the motor's speed increase proportionally, up to its maximum speed at 100%.
4.  To change the direction, you can modify the `HAL_GPIO_WritePin` states in the code and re-flash.
